# Audit Outputs

This directory contains provenance and reproducibility audits
performed on the Honeybee–Drosophila computational model.

Important conclusions:

1. The validated stimulus continuum has CS+/CS− Hamming distance 28.
2. The historical value 44 represents strict geometric candidates
   among 100 stimuli.
3. The historical v12.2.16 conditions are:
   NONE, PN_KC_ONLY, KC_EN_ONLY and FULL.
4. These historical mechanistic conditions are distinct from the
   four v13.3E factorial model conditions.
5. Therefore historical v12.2.16 PI profiles should not be directly
   merged with v13.3E network-level NPZ outputs.
6. Audit results are model-level computational findings and should
   not be interpreted as direct biological causal evidence.
